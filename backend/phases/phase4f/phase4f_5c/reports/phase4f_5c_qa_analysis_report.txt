3. EM vs F1 GAP ANALYSIS
======================================================================

  A1 achieves high F1 (>30%) but no EM on 15 examples.
  Dominant mismatch type: SUBWORD_TOKENIZATION (12/15)

  Example pattern:
    Gold:  "20.3 percent"
    A1:    "20. 3 percent"
    F1:    40.0% (3/5 tokens match)
    EM:    False (space inserted by WordPiece)

  This is NOT a model failure — it is a tokenizer artifact.
  The model correctly identifies the answer span but WordPiece
  splits "20.3" into tokens ["20", ".", "3"], which decode with
  spaces as "20. 3".

  Under relaxed normalization (ignoring whitespace around dots),
  ~12 additional A1 predictions would become exact matches.

4. NUMERIC QA AUDIT

    SUBWORD_DECIMAL:  12 (correct span, tokenizer splits decimals)
    PARTIAL_OVERLAP:   4 (wrong number but some token overlap)
    WRONG:             2 (completely wrong)

  Common patterns:
  - "$847.3 million" -> "847. 3 million" (decimal split + currency)
  - "$245,000" -> "245, 000" (comma creates separate tokens)
  - "$3.47" -> "3. 47" (decimal split, no surrounding context)
  - "1000" -> "1000 requests per minute" (extra context words)

  Root cause: WordPiece tokenization at character boundaries.
  This is a REPRESENTATION-level issue, not a model or training issue.

12. FIVE-LEVEL ROOT CAUSE ANALYSIS
======================================================================

  LEVEL 1 (DATA):
    - Test set has 0 UNANSWERABLE examples — cannot evaluate abstention
    - Test set is 50.2% TABLE_CELL — skewed to hardest category
    - A0's training data (414K samples) includes table-heavy patterns

  LEVEL 2 (REPRESENTATION):
    - WordPiece tokenization splits decimals: 20.3 -> "20. 3"
    - This prevents EM on ~60% of NUMERIC/DIRECT_SPAN examples
    - Table context is pipe-delimited text, losing structure

  LEVEL 3 (MODEL):
    - A0's 414K training provides section-level comprehension advantage
    - A1/A2 (fresh pretrained) cannot match this on 571 examples
    - A0's conservative abstention hurts on all-answerable test set

  LEVEL 4 (TRAINING):
    - A2 overfits (val_EM=11.2% vs test_EM=0.9%)
    - 2 validation documents insufficient for checkpoint selection
    - 3 epochs may be too few for BERT to generalize

  LEVEL 5 (EVALUATION):
    - EM metric is too strict for subword-tokenized outputs
    - No UNANSWERABLE test examples limits evaluation scope
    - Test set composition (4 docs, 50% TABLE_CELL) may not represent
      deployment scenarios
