None of these files currently exist. They will be created by train.py and evaluate.py

NOTE: evaluate.py implements the following metrics:
  - Exact Match (EM)
  - Token-level F1
  - Answerability accuracy
  - Abstention accuracy
  - Spurious answer rate
  - Per-category metrics
  - Confidence (start/end softmax)
  - Failure taxonomy (structural)

NOT implemented in evaluate.py:
  - ECE (Expected Calibration Error)
  - Brier score
  - Phase 4B-specific metrics

These metrics are NOT included and would require changes to evaluate.py
if needed in a future phase.
