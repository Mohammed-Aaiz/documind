============================================================
11. CONCLUSION
============================================================

  THRESHOLD_UNSTABLE

  The F2 model's CLS/no-answer signal is:
  - WEAK (CLS avg 0.6 vs best answer 1.3)
  - UNCALIBRATED (answerable/unanswerable distributions overlap)
  - UNSTABLE (tiny threshold changes cause large behavioral shifts)

  The threshold approach can recover ~19% abstention on benchmark
  but at the cost of 28% false abstention on answerable questions
  and 81% spurious rate on unanswerable questions.

  This is WORSE than the production model (A0) which achieves
  64.3% abstention with only 8.2% spurious rate.

  The root cause is NOT the decision rule — it's the underlying
  model's weak CLS signal. No threshold can compensate for a
  model that doesn't learn a strong no-answer representation.

  RECOMMENDED NEXT EXPERIMENT:
  Train a model with much higher unanswerable ratio (~50%)
  using class-balanced sampling, which should produce a
  stronger CLS signal that makes thresholding viable.
